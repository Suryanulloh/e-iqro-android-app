# E-IQRO: Aplikasi Belajar Iqro untuk Anak Usia Dini

Aplikasi Android untuk membantu anak usia dini belajar mengaji dengan metode Iqro, dibuat dengan MIT App Inventor sebagai bagian dari penulisan ilmiah (nilai A) di Universitas Gunadarma: "Pengembangan Aplikasi E-IQRO untuk Pembelajaran Anak Usia Dini Berbasis Android Menggunakan MIT App Inventor".

## Tujuan
Menyediakan media belajar yang menarik dan mudah dipakai agar anak dapat mengenal huruf hijaiyah dan belajar membaca Iqro secara mandiri.

## Fitur
| Fitur | Keterangan |
| --- | --- |
| Layar pembuka | Tampilan awal "Mari Mengaji Iqro" dengan tombol masuk |
| Menu utama | Pilihan Al-Fatihah, Huruf Hijaiyah, Membaca Iqro, dan Quiz |
| Huruf Hijaiyah | Daftar huruf hijaiyah berwarna dengan tombol navigasi sebelumnya, beranda, dan selanjutnya |
| Membaca Iqro | Materi Iqro per halaman (contoh: Iqro 1 halaman 1) dengan navigasi antar halaman |
| Quiz | Soal pilihan ganda "Huruf hijaiyah apakah ini?", dengan tombol ulangi dan soal selanjutnya |
| Hasil quiz | Layar "Quiz Selesai" dengan pilihan ulangi quiz atau kembali ke menu |

Aplikasi juga memuat materi audio untuk pelafalan huruf. [Cek dan sesuaikan: audio diputar saat huruf ditekan atau di bagian lain.]

## Cara memasang
1. **Pakai APK:** unduh `E-Iqro.apk` dari halaman [Releases](../../releases), izinkan pemasangan dari sumber tidak dikenal di ponsel Android, lalu pasang.
2. **Pakai file sumber:** buka [MIT App Inventor](https://appinventor.mit.edu/), pilih **Projects, Import project (.aia) from my computer**, lalu pilih `e-iqro.aia`.

## Catatan
- Aplikasi dibuat untuk keperluan penulisan ilmiah dan belum dirilis di Google Play Store.
- Ilustrasi dan materi pembelajaran di dalam aplikasi berasal dari sumber yang dicantumkan di bawah. [Isi sumber gambar dan audio.]
